# RealSignal 5.5.86 — verified IA pilot

## Scope

This is a limited desktop production pilot, not all-channel IA certification.
Only channel 10 (Classic Rerun TV) and channel 150 (Classic Cartoons) automatically
use the repaired playback shelf. All other channels retain their existing client
path. Mobile, Cast receivers and connected Cast senders are not automatically
enrolled. OK/Vimeo sources and the
lineup are unchanged; no channels are hidden or removed.

## Delivered behavior

- One reservation order feeds guide, preload, Next and end-of-file playback.
- Actual decoded playback, not preparation, records viewing history.
- Complete-series files can become separate episode records.
- Deeper catalogs survive shallow refreshes and concurrent owner updates.
- Selected-file runtime, geometry and transport qualification govern admission.
- Background repair harvests await catalog persistence before acknowledging;
  failed writes retry instead of silently losing discoveries.
- A desktop allowlist prevents unverified stations from entering the new path.

## Evidence before release

- Final local behavioral suite: 82 tests passed, zero failures.
- All 49 distinct local Node commands extracted from CI passed.
- Three live reservation rotations: channel 10 and channel 150 each returned
  three qualified items per rotation, nine distinct files, zero repeats.
- Actual browser pictures: Flintstones, Scooby-Doo, Jetsons and Bonanza;
  Next selected a different cartoon, and guide open/close worked.
- Bonanza remained visibly playing past three minutes; its initial frame was
  1.611 seconds. Next advanced to Dragnet rather than replaying Bonanza.
- The latest cartoon sample had a 10.113-second cold first frame and a
  1.917-second Next. Later buffering triggered recovery to another program.
  Startup and long-play stability are not yet certified as instant television.
- Grand Prix failed the fresh release gate with two ready items. It is not
  enrolled, despite passing an earlier sample. The previously reported 17 weak
  lanes also remain outside the rollout.
- No physical mobile or Cast certification is claimed for the repaired protocol.
- Independent release review identified connected Cast senders crossing the
  canary boundary. A red/green connection-transition test now verifies they
  dynamically return to legacy playback, then rejoin after disconnecting.

## Hosted backend gate

- Backend commit `6fcfeb2` passed hosted CI, API deployment, relay deployment
  and Pages deployment before client activation. The API deploy step actually
  ran; this was not a missing-credentials skip.
- Production channel 150 returned three qualified files in each of three
  rotations, nine distinct files and zero repeats (3.424/3.136/1.128 seconds).
- Production channel 10 initially underfilled on its third rotation while
  background ingestion was still growing the bank. A separate serial retry
  then returned three qualified files in all three rotations, nine distinct
  files and zero repeats (0.659/0.256/0.175 seconds); reported catalog depth
  grew from seven to 97 candidates. Candidate count is not decoded-playback
  certification. The cold-underfill finding remains a limitation, not erased
  by the successful warmed retry.
- These measurements cover API qualification/reservations, not first visible
  frames. Hosted client pictures are checked separately after publication.

rollback. Preserve the existing cache/history records; no migration deletes data.
The pre-repair baseline is commit `90ada75`, build 5.5.85.
