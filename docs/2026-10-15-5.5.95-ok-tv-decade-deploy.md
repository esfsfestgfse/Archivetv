# 5.5.95 — OK TV decade deployment hardening

The API deployment remains authoritative even when its optional canonical
metadata repair cannot access D1 directly. The repair still runs after every
deployment and reports a warning when the Cloudflare token lacks D1 edit
permission, but it can no longer mark an otherwise healthy Worker deployment
as failed.

All-decade background indexing remains active. Hidden decade profiles stay out
of the public guide until their independent depth and freshness gates pass.
