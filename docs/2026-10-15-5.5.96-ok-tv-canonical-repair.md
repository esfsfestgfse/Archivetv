# 5.5.96 — OK TV canonical metadata repair

Background OK TV discovery now repairs a bounded set of legacy canonical
TVmaze records through the Worker's own D1 binding. Existing verified episodes
with missing premiere years can therefore join the correct decade catalog
without requiring broader Cloudflare token permissions.

The repair never runs on first-play requests, never changes media URLs, and is
limited to canonical TVmaze identities in the verified OK TV parent catalog.
Hidden decade channels remain hidden until their independent release gates
pass.
