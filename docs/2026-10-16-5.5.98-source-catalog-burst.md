# RealSignal 5.5.98 — Source Catalog Burst Safety

## What changed

- Raised the bounded source-catalog viewer limit from 60 to 240 requests per minute.
- Kept provider discovery, hydration, and upstream adapter limits bounded separately.
- Extended the decade certification sample to include the verified 1970s and 2010s rails.

## Why

Opening the guide while quickly changing Source Suite channels can legitimately request
more than sixty catalogs in a minute. The previous edge guard falsely treated that as
abuse and produced empty certification shelves. This release preserves abuse protection
while allowing ordinary channel-surfing and a complete health check.

- OK TV decade profile tests pass locally.
- The deployed API must pass the five-profile low-concurrency certification before any
  additional decade channels are exposed.
