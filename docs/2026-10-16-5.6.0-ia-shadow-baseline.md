# RealSignal 5.6.0 — IA Three-Lane Shadow Baseline

This release adds a measured shadow-catalog repair path for Classic TV,
Classic Cartoons, and Game Shows.

- Archive collections are expanded at file level so individual episodes retain
  their own playback identity.
- Per-family, per-collection, and decade-balance gates reject shallow or
  repetitive candidates from promotion.
- The API exposes a read-only comparison endpoint with an explicit promotion
  verdict and reasons.
- Public playback, guide routing, and normal channel switching remain on the
  existing production fallback. No station is promoted automatically by this
  release.

The first local measured run accepted Classic TV and held Classic Cartoons and
Game Shows for additional decade balancing. Holding a weak shadow catalog is
intentional: it prevents a shallow replacement from reaching viewers.
