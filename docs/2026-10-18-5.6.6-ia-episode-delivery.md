# RealSignal 5.6.6 — IA episode delivery

## Scope

Classic Rerun TV (10), Classic Cartoons (150), and shared series/edition admission fixes. Existing channel identities, runtime floors, landscape requirements, session reservations, and game-show eras are preserved. OK, Vimeo, FAST, and Cast protocols are unchanged.

## Reproduced failures

- A production cartoon session exhausted seven playable records and then repeated; its ready shelf fell to two and then one.
- A Danish-labelled Spider-Man episode was accepted despite the English-edition requirement.
- Jack Benny episodes featuring George Burns received a Burns & Allen series label, defeating show-family balancing.
- An Archive download redirect exceeded a twelve-second local probe while the metadata-provided URL for the same Top Cat file returned video successfully.

## Changes

- Retain 282 metadata-qualified TV episode candidates across nine reviewed collections, and 168 cartoon candidates across eight reviewed collections. These are recovery candidates, not a claim that every file is always playable.
- Spread those records across the collections' full episode ranges and interleave the series; preserve collection indexes for continued background expansion.
- Carry Archive's actual direct delivery hosts with exact file identity and the canonical download URL as fallback. Transport checks still run before admission; static metadata is never labeled transport-verified.
- Prefer the program's title identity over guest names, including old stored series labels.
- Reject explicitly foreign-dubbed editions on English-focused stations and bumper-only Noods compilations on Classic Cartoons.

## Local evidence

- Cold cartoon queue: three ready records in 504 ms in one canary; subsequent requests 49–241 ms. These are queue timings, not first-visible-frame timings.
- Warm twenty-skip canaries: twenty distinct episodes per station, three ready records throughout, no rejected files or cycle resets. Catalogs reached 433 admitted TV records and 171 admitted cartoon records in this run; live counts vary as validation and discovery continue.
- Observed browser playback: Top Cat, Next to Clutch Cargo, then Benson on channel 10; decoded dimensions and advancing playback time confirmed. Guide open/close and current/next listings worked.
- Focused tests and the workflow's Node checks run before publishing. Hosted CI and production checks are separate release checks.

## Limits

This is a two-station repair, not certification of every IA channel or physical mobile/Cast hardware. Provider availability and CDN assignments can change; canonical fallback and background metadata refresh remain necessary. Existing unrelated audit artifacts are not part of this release.
