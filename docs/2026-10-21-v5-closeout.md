# RealSignal 5.6.29 — Version 5 closeout

## Decision and scope

Freeze this bounded Version 5 repair batch after deployment verification. This
is not a claim of zero unknown failures or a new all-device certification.
Discuss Version 6 before adding features. No channels were hidden, renumbered,
merged, or added. Roku and Vimeo work remain paused.

## What changed

- Corrected three stale recovery filenames: the Mr. Rhodes S01E06 file on
  Modern Rerun TV (11), and the two nested Colonial Naturalist reels on 217.
  Shared admission rejects the exact obsolete paths in saved catalogs and
  client caches without rejecting the corrected files or erasing watch history.
- Added 20 long-form file records from eight Archive parents to Range & Field
  (83), including 13 complete Olympic archery sessions and seven additional
  archery, bowhunting, and trap/skeet programs. All 20 passed video range-response
  checks and have landscape dimensions and runtimes of at least 15 minutes.
  Two split Olympic files were not added to the reviewed starter bank; normal
  collection discovery can still expose correctly identified session parts.
- Changed only channel 83's measured-depth cache revision so its enlarged bank
  is not pinned behind the previous cached catalog. Rotation ownership and
  the persistent watched ledger are unchanged.
- The cross-family browser check reproduced a Darkroom (515) genre mismatch:
  a radiography exam lesson. The server profile and both client descriptors now
  exclude clinical radiography/radiology and exam-preparation signals. A new
  regression test preserves photography programming while rejecting the exact
  observed lesson, including retained client-cache qualification.
- Desktop title, mobile title, visible builds, asset cache queries, API release,
  and the API contract expectation advance together to 5.6.29.

## Remaining limits, not hidden failures

- One Digimon complete-series parent returned no usable file manifest; retries
  were unavailable. Do not count its missing metadata as verified depth or
  permanently ban its whole channel.
- Corrected Mr. Rhodes and Colonial Naturalist reel 2 returned HTTP 206 video.
  Reel 1's corrected path is listed in metadata but returned a server error;
  selective retries also failed. It remains transport-unconfirmed. Existing
  admission/recovery must skip a failed response rather than serve a sibling.
- Catalog exhaustion still permits repeats. Channel 83 improved from the
  earlier eight-item observed window to 32; it did not become endless.
- No new precise first-frame timing, all-file audiovisual review, or physical
  Chromecast/Roku certification was performed. Cast has no changes in this
  release; Roku remains paused.
- Live TV browsing populated 182 FAST entries and Radio populated its station
  directory, but neither observation alone certifies sustained media playback.
  An OK Movie test built an embed without a confirmed visible frame; Chrome
  also exposed an injected third-party video-extension frame. Do not attribute
  that ambiguity to the app or call the cross-family playback gate green.
- External provider availability and embed restrictions can change independently
  of a release. Do not label a metadata or HTTP check as visible playback.

## Release and rollback

Normal main push triggers the existing CI, API, relay, publishing, and Pages
workflows. Verify all applicable jobs and public desktop/mobile/API stamps
before reporting this release live. Preserve raw audit artifacts and unrelated
untracked files.

Previous stable reference: `9d4874e44d0dcc5c982da11703b25157f77752dc`
(5.6.28). If this release causes a reproducible regression, revert the closeout
commit through a new reviewed commit and the normal deployment workflows;
do not reset main or delete viewing history. No schema migration was added.

## Discussion before Version 6

Separate catalog identity/completeness from transport health and decoded-frame
health. Prioritize measured repeat windows and provider recovery over another
rewrite or a channel-count increase. Agree on the Version 6 feature scope and
release gates with the user before implementation.
