# RealSignal 6.0.42: IA duplicate-file identity

## Bounded repair

This follows the hash-confirmed Hard Count repeat recorded in 6.0.41. No new
channel audit, discovery provider, migration, catalog reset or history wipe.

- Collection expansion now groups files within one Archive parent using its
  explicit original/derivative links or identical valid SHA-1 plus byte count.
  Existing filename/encoding grouping still applies.
- Missing references, cycles and malformed hashes cannot create a merge.
  Matching uses the complete media manifest, including MKV/AVI originals,
  while artwork cannot connect programs. Known runtimes across each whole
  group must remain compatible, including when the original duration is unknown.
- The representative file retains its own filename, URL, runtime and geometry.
  No identity from one file is grafted onto another file's transport.
- The two already-cached `dvd-transfer-224` Super Bowl X filenames receive a
  narrowly reviewed shared identity. This is supported by Archive's matching
  SHA-1/size and original-file relationship, not a rule stripping title numbers
  from every DVD or series.
- Standard played-only and guarded reserve/commit history both exclude the
  second cached copy while an unseen program remains. Existing history survives.
  An already-saved two-copy reservation also collapses to a single slot.

parts; both rotation protocols choose the unseen program instead of the alias.
Negative cases retain separate episodes, parts, excerpts and unreviewed parents.

## Limits

New grouping uses metadata already fetched during background collection
expansion. It adds no media/discovery requests to a tune and does not increase
the foreground shelf size. Metadata-less older catalogs are not magically
hash-deduplicated; the observed cached alias is repaired immediately, while
other parents benefit when their existing metadata expansion refreshes them.
Cross-parent reuploads are not automatically combined.

This release does not claim a full-lineup freshness percentage or universal
startup improvement. Previously recorded failed-file recovery delays and genre
contamination remain separate work. Physical phone/Cast certification and the
full IA soak were not repeated for this repair. Version 7 is not certified here.
