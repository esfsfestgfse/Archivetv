# RealSignal 6.0.26 — Balanced IA catalog windows and browser-confirmed genre repairs

The whole-IA audit in 6.0.25 covered all 170 canonical profiles and 13 aliases. Follow-up Chrome testing found two failures not visible in stored metadata alone: Disaster Desk played a Roblox video essay (including War Thunder sponsorship/gameplay), and Saturday Morning played a traditional Indonesian shadow-puppet performance rather than a children's television program. Archive metadata confirmed both formats; the puppet item's language field misleadingly said English.

Disaster Desk now rejects gaming/Twitch formats and the observed unrelated literacy-gap metaphor. Its unrelated Twitch VOD had stalled the first tune until the 12-second recovery deadline. Blocking that genre contamination removes the observed failed first attempt without changing playback deadlines or banning genuine disaster documentaries. Saturday Morning excludes the one confirmed cultural-performance source; Sesame Street and other children's puppet programs remain eligible. All admission copies and persisted catalog reads use the same scoped rules.

Documentary Hour also exposed a shared ordinary-IA query problem: importing a large new collection could fill the 96-record database window and hide older healthy series before rotation ran. The ordinary IA window now ranks resolved media first and interleaves stored series/parent families, retaining explicit metadata URL fallbacks and bounded response size. The existing freshness ledger orders unserved/oldest-served episodes within each family, so a show can advance beyond its original first 96 files. This uses the same SQL window-function approach as the existing repaired IA path. Source Suite, OK/Vimeo, strict transport qualification, catalogs, histories and promised reservations retain their existing behavior.

A real SQLite regression first reproduced a one-series shelf behind 180 new collection records; the fixed path includes older Nature, Science and History programs in the candidate window. Existing tests protect older resolved media from metadata-only bursts. Editorial cases reproduce the browser leaks and preserve valid eyewitness documentaries, children’s puppets and appropriate cultural channels.

This release retains the six reviewed single-series identity repairs from 6.0.25. Full offline regression and targeted hosted playback/guide checks follow before completion. The 170-profile stored-data audit and local rotation simulations are not a claim of decoded playback certification for the entire lineup.
