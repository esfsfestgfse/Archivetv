# RealSignal 6.0.28 — Source Suite catalog handoff and freshness

The regular YouTube/PeerTube client consumed only the five-item ready shelf and ignored the larger requalified candidate catalog returned by the API. It also retained/sent only 24 actual-play IDs, truncated its catalog to 96 before freshness ordering, and the ordinary server read selected only the newest 96 rows. These independent limits made deeper stored catalogs feel like the same small playlist.

The client now consumes the qualified candidate union, keeps a bounded 512-item working set and 1024 actual-play IDs, and orders fresh programs before truncating that working set. The small ready buffer is retained; D1 retains the catalog union beyond either playback batch size. Server Source Suite history and reads now prioritize personal unseen programs and older unserved records. Recent IDs are passed as one JSON SQL parameter. When only a few unseen programs remain they stay ahead of repeat fallback tails. Healthy catalogs no longer launch discovery merely because their ready shelf has fewer than 12 slots.

The initial read-only audit covered all 70 YouTube/PeerTube profiles: no empty returned catalogs, 11 below 12 admitted rows, one below five. These were qualified windows capped at 96, not full stored totals or decoded-video certifications. One bounded serial maintenance refresh targeted those 11 without deleting catalogs, resetting history or expanding providers. Several lanes gained material; Black Stage remains shallow and is not padded. A temporary PeerTube cooldown affected an intermediate Field Notes measurement and must not be reported as deleted content.

Actual SQLite and client VM regressions reproduced older-program starvation, personal-history truncation, the five-only handoff and unnecessary background refills, then passed after repair. Existing language, runtime (at least 15 minutes, with stricter movie floors), landscape, AI/podcast/fan-content and channel editorial rules remain. IA and OK/Vimeo catalog behavior, channel numbers and lineup identities are preserved. No channels were merged or hidden.

Independent review caught automatic EOF stopping once the now-longer history covered an exhausted catalog. A runtime regression reproduced it. Confirmed server exhaustion now permits the oldest watched program to continue while background discovery runs; an unseen item always wins, and history is retained. All 93 offline gate commands pass. Targeted local Chrome playback shows actual decoded cartoons and different programs on Next; hosted and wider device checks remain separate.

The first post-maintenance window sample increased Comedy Circuit 6→18, Documentary Desk 7→21, Holiday Cartoon & TV Club 9→14, Memory Bank 11→15, Newsreel Exchange 9→33 and Stage Door 8→40. These are admitted-window counts, not a promise that all clips decoded or all providers were available simultaneously. Black Stage, Classroom, Comfort Television and Foodways still need focused depth work. This is a staged Version 7 reliability improvement, not Version 7 certification or a claim of infinite content.
