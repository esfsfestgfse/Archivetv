Plan of Action

What to ship next, in order.

Ordered by user-visible impact per unit of work. The top three land solid infrastructure wins; the bottom three are architectural moves that require new external plumbing (Cloudflare Workers).

Fix 1

Universal fetchJSON with relay fallback

Effort: M · Impact: Very High

The pattern that fixed Sky Beacon today (try direct → fall through to relay) needs to become the default for every live-data channel. Add a new fetchJSONResilient(url, tag) wrapper that does direct-first then relay-fallback and returns the parsed JSON. Convert Gas Ticker, The Grid, Newsstand, Ham Radio, Tropical Watch, Historic Waco, and the ISS Tracker's calls to use it. Eliminates every "Flaky" row above in one architectural change.

Scope: ~1 new function (30 lines), ~10 call-site conversions, 2 files. Rollback risk: low — additive.

Fix 2

Highway Cams · rebuild the pool with verified streams

Effort: M · Impact: Medium

The 3 DOT YouTube channels currently in the pool (KC Scout, MassDOT, UDOT) all rely on YouTube's /embed/live_stream?channel=X URL, which was quietly deprecated. Fix path options:
· Best: replace with direct HLS URLs from state DOT ArcGIS traffic-cam servers where they exist (many DOTs publish direct .m3u8 streams — Texas TxDOT, California Caltrans QuickMap, Washington WSDOT).
· Fallback: switch to a mixed-mode pool of image-refresh cams (JPG polling every 3-5 sec) instead of live video. Many DOTs publish still-image cams that update reliably.
· Retreat: merge Highway Cams into Live Cams (303) as a filtered sub-category and drop channel 302 entirely.

Scope: LIVECAMS_STREAMS pool audit + new type:"jpg-refresh" stream type in tuneLiveCams. 2 files.

Fix 3

Feed Health monitor · surface flaky rows to the user

Effort: S · Impact: Medium

The Settings → Feed Health panel already logs every fetch success/failure via nlog(). Add a compact per-channel health chip so a user can see "these channels are struggling right now" without opening DevTools. Two colors: green (last fetch succeeded within last hour) / amber (last fetch failed). Sourced from the existing NETLOG ringbuffer.

Scope: ~40 lines in the Settings render path. Zero API surface change.

Fix 4

Ship Tracker · Cloudflare Worker for aisstream

Effort: L · Impact: Medium

aisstream.io explicitly documents "we block direct browser connections". The only path to Ship Tracker working is a Worker that proxies the aisstream WebSocket. Similar to the existing sports-cache.tdy1990.workers.dev. Requires: (a) aisstream account (already have keys), (b) a new Worker (call it ais-relay.tdy1990.workers.dev), (c) client-side change to point at the Worker instead of aisstream.io.

Scope: new Worker script (~50 lines), one client-side URL change. External infra: 1 new Worker deployment.

Fix 5

The Ranger + Highway · promote HLS-first, embed as last resort

Effort: M · Impact: Medium

YouTube channel-based embeds are ecosystem-fragile forever. Restructure LIVECAMS_STREAMS so HLS streams are preferred over YouTube for the same conceptual cam. Add optional fallback: field per entry — if the primary stream fails to load within 6 seconds, promote the fallback. Reduces the visible impact of any single stream going dark.

Scope: LIVECAMS_STREAMS shape change + tuneLiveCams promotion logic. 2 files.

Fix 6

ISS Tracker · swap to wheretheiss.at

Effort: S · Impact: Small

api.open-notify.org is timing out today and has been intermittent for months. wheretheiss.at (api.wheretheiss.at/v1/satellites/25544) returns the same lat/lon data, has CORS *, and is actively maintained. One-line source swap.

Scope: 1 URL string, 2 files.
